AI Technology

Understanding ChronicCare AI

ChronicCare AI is an academic machine-learning application designed to demonstrate how trained classification models can be integrated into a Django web application.

Technology Stack

Built with Python and AI

Each technology has a specific role in the ChronicCare AI architecture.

🐍

Python

Core programming language used for machine learning and backend development.

🌐

Django

Python web framework responsible for routing, requests, templates and application logic.

🤖

Scikit-learn

Used for training, preprocessing and machine-learning classification pipelines.

🎨

Tailwind CSS

Provides the responsive and modern user interface for the application.
